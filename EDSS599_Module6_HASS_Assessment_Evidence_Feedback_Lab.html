Assessment lens

Assessment is useful when it produces evidence that informs teaching or supports a defensible judgement. The format alone does not determine whether an assessment is diagnostic, formative or summative — the key question is how the evidence will be used.

Core principle: assessment matters because evidence changes what happens next.
